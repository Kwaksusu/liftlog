# LiftLog

휴대폰용 운동 기록 웹앱입니다. 설치 과정 없이 브라우저에서 바로 실행됩니다.

## 기능
- 루틴 버튼(A, B, 직접 추가)과 자유 운동
- 세트마다 무게·횟수·RPE(@5~@10, 0.5 단위)·완료 체크
- 종목별 휴식 타이머(1~4분). 시간이 지나면 −0:12처럼 초과 시간을 표시
- 종목별·세션별 볼륨, 이번 주와 지난주 S·B·D·O 볼륨
- 기록: 스쿼트·벤치·데드·OHP 그래프(e1RM / 최고 작업 무게), 주간 볼륨 표
- 달력: 운동한 날에 루틴 첫 글자 표시
- 1RM 계산기(RPE 표 방식)
- 설정: 루틴과 종목 편집, 휴식 시간, 백업 내보내기·불러오기

## 데이터
기록은 이 휴대폰 브라우저의 localStorage에만 저장됩니다. 설정 → 백업 → 내보내기로 가끔 백업하세요.

## 업데이트할 때
`sw.js` 파일의 `VERSION` 값을 올려야 휴대폰에 새 버전이 확실히 반영됩니다.
